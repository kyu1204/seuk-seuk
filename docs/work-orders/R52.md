## 스펙
- 마이페이지 h1 `mypage.title` 값 "계정". 카드 3개 세로(`max-w-3xl flex flex-col gap-6`):
  1. 프로필 카드: 제목 `mypage.profile.title` 값 "프로필", 2열 그리드(이름 입력, 이메일 읽기 전용 + 힌트 `mypage.profile.emailHint`("로그인과 알림에 사용됩니다.")), 하단 가입일 `mypage.profile.joinedAt` + 저장 버튼 `mypage.profile.save`("변경 사항 저장")(이름 변경 액션이 없으면 버튼 생략).
  2. 플랜과 사용량 카드: 제목 `mypage.plan.title`("플랜과 사용량"), 설명 "{{plan}} 플랜 · 다음 결제 {{date}}"(`mypage.plan.summary`; 구독 없으면 `mypage.plan.free`("베이직 플랜 · 무료")), 오른쪽 `mypage.plan.manage`("결제 관리") outline → /bills. 아래 2열 진행 바(이번 달 보낸 문서, 추가문서 잔여) — R21 의 usage-widget 요약 컴포넌트를 재사용할 수 있으면 재사용.
  3. 계정 삭제 카드: `border-destructive/40`, 제목 `mypage.dangerZone.title` 값 "계정 삭제", 설명 `mypage.dangerZone.deleteWarning` 값 "계정을 지우면 문서, 서명본, 템플릿이 모두 영구히 사라집니다. 진행 중인 발행이 있으면 먼저 정리해 주세요.", 버튼 `mypage.dangerZone.deleteAccount` 값 "계정 삭제"(outline destructive). 기존 이메일 확인 폼은 다이얼로그 안에서 유지. 성공/실패 문구: `deleteSuccess` 값 "계정을 삭제했습니다.", `deleteError` 값 "계정을 삭제하지 못했습니다. 다시 시도해 주세요."
- page.tsx 의 "프로필을 불러오는데 실패했습니다" → `mypage.error.loadProfile` 키(값 "프로필을 불러오지 못했습니다. 새로고침해 주세요.").
- bills-content: 헤더는 spec 페이지 헤더 패턴(카드 래퍼 없음), Tabs 는 Card 밖에서 `mb-6`. 빈 상태: `bills.noSubscription.title` 값 "현재 이용 중인 플랜이 없어요", description "플랜을 구독하면 문서 한도와 템플릿을 쓸 수 있어요.", action "플랜 둘러보기"; `bills.noTransactions` 값 "아직 결제 내역이 없어요." `bills.*` 중 locale 에 없는 키(created, historyDescription, totalDocuments, viewDetails, noDocuments.*) 를 ko/en 에 추가하고 인라인 폴백 제거.
