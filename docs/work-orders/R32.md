# R32 발행 화면 리뉴얼

## 파일 (각 `.test.tsx` 먼저)
- `app/(document)/publish/page.tsx` — 테스트: 소스에 한글 부재(`[가-힣]`), `searchParams` 존재.
- `app/(document)/publish/components/PublishPageContent.tsx` — 테스트: `publish.description` 존재.
- `components/publish/publish-form.tsx` — 테스트: `publish.password.optional` 존재, `text-gray-500` 부재, `focus()` 존재.

## 스펙
- page.tsx: h1 하드코딩 제거, `searchParams.doc` 를 PublishPageContent 에 `preselectedDocumentId` 로 전달.
- 헤더: 뒤로가기 + h1 `publish.title` + 설명 `publish.description`("선택한 문서를 링크 하나로 묶어 보냅니다. 받는 사람은 링크에서 바로 서명해요.").
- 본문 `grid lg:grid-cols-[minmax(0,1fr)_360px] gap-6 items-start`.
  좌측 카드: 제목 `publish.documents.title`("보낼 문서") + `publish.documents.count`("초안 {{total}}개 중 {{selected}}개 선택") + 오른쪽 `publish.selectAll` 링크. 목록은 카드형 행(`flex items-center gap-3 rounded-lg border p-3`, 선택 시 `border-primary bg-primary/5`)에 `components/ui/checkbox`, 문서명, 메타 `publish.documents.meta`("{{pages}}쪽 · 서명 {{signatures}}"). 서명 칸이 0개인 문서는 체크 비활성 + 메타에 `publish.documents.noAreas`("칸 없음 · 발행 전 서명 칸을 지정하세요"). `max-h-96` 제거, 목록 전체 표시. preselectedDocumentId 가 있으면 초기 선택.
  우측 카드: `publish.name`(플레이스홀더 `publish.namePlaceholder` 값 "예: 9월 신규 계약 · 김지우", 힌트 `publish.nameHint`("받는 사람 화면 맨 위에 보입니다.")), `publish.password` + 라벨 옆 `publish.password.optional`("선택") — 비어 있으면 비밀번호 없이 발행(서버 액션이 빈 값을 허용하는지 확인하고, 허용하지 않으면 액션 호출 전 undefined 로 전달), 힌트 `publish.passwordHint`("걸어 두면 비밀번호를 아는 사람만 문서를 볼 수 있어요."), `publish.expiration` 기본값 오늘+14일, 힌트 `publish.expirationHint` 값 "이 날짜가 지나면 링크가 열리지 않습니다.". 제출 버튼 `publish.submit` 값 "링크 만들기", 진행 중 `publish.submitting` 값 "링크 만드는 중…".
- 검증 에러는 해당 필드 아래 표시하고 첫 에러 필드로 `focus()`.
- 성공 후 이동은 기존 동작 유지하되 토스트 `publish.success`("링크를 만들었어요. 받는 사람에게 공유하세요.").
- 에러 `publish.errorPublishing` 값 "발행하지 못했습니다. 잠시 후 다시 시도해 주세요."

## locale
publish.description, publish.documents.*, publish.password.optional, publish.nameHint, publish.passwordHint, publish.success, 값 변경 키들. en 대응.
