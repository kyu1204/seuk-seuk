# R61 에러 문구 규칙·용어 표준·하드코딩 한글 UI i18n 화

## 범위
locale 값 정리와 남은 클라이언트 하드코딩. 서버 액션(`app/actions/**`)의 문자열은 건드리지 않는다.

## locale 값 변경 (ko; en 은 대응 영어. 먼저 ko.test.ts 에 각 키의 새 값을 assert)
- "~중 오류가 발생했습니다" 패턴 전부: `grep -n "오류가 발생" locales/ko.ts` 로 나온 모든 키를 "무엇을 못 했는지 + 다음 행동" 형식으로 고친다. 최소 다음은 정확히 이 값으로:
  - documentDetail.errorUpdateArea="서명 칸을 저장하지 못했습니다. 다시 시도해 주세요."
  - documentDetail.errorDownload="파일을 내려받지 못했습니다. 다시 시도해 주세요."
  - documentDetail.errorDelete="문서를 삭제하지 못했습니다. 다시 시도해 주세요."
  - templates.error="템플릿 작업을 완료하지 못했습니다. 다시 시도해 주세요."
  - templates.create.unexpectedError="템플릿을 저장하지 못했습니다. 문제가 계속되면 문의해 주세요."
  - usage.error.title="사용량을 불러오지 못했어요", usage.error.message="새로고침해 주세요."
  - dashboard.error.loadMore="문서를 더 불러오지 못했습니다. 다시 시도를 눌러 주세요."
  - contact.error.description="문의를 보내지 못했습니다. 잠시 후 다시 보내 주세요."
  - sign.progress.imageTimeout="문서를 불러오는 데 너무 오래 걸립니다. 네트워크를 확인하고 다시 시도해 주세요."
  - sign.progress.imageLoadFailed="문서를 불러오지 못했습니다. 새로고침해 주세요."
  - checkout.success.message="결제가 완료됐습니다. 바로 이용하실 수 있어요."
- 용어: `grep -n "크레딧\|제거\|양식\|로딩 중\|저장중\|영역추가\|개인정보 처리방침\|받은함\|귀하" locales/ko.ts` 결과를 각각 추가문서 / 삭제 / 템플릿 / 불러오는 중… / 저장 중… / 칸 추가 / 개인정보처리방침 / 받은편지함 / (귀하 삭제) 로 고친다. "해주세요" → "해 주세요"(띄어쓰기) 전체 치환. "일괄서명"→"한 번에 서명", "일괄 적용"→"모두 적용".
- 홈·요금제 CTA 통일: pricing.free.cta="무료로 시작하기", pricing.starter.cta="스타터로 시작하기", pricing.pro.cta="프로로 시작하기".
- 미사용 키 삭제(ko/en 동시): `pdf_*` 8개, `checkout.billing.*`, `mypage.error.*` 중 미사용, `consent.error`, `plan.Starter/Pro/Enterprise`(코드에서 사용 여부 grep 후 미사용만). 삭제 전 `grep -rn "<key>" app components lib` 0건 확인.
- 의미 중복 키 통합은 하지 않는다(범위 밖).

## 하드코딩 한글 UI (각 파일 `.test.tsx` 먼저: 한글 부재)
- `app/(document)/document/[id]/components/DocumentDetailPage.tsx` 의 "PDF 페이지가 아직 준비되지 않았습니다." → `documentDetail.pdfNotReady`; 인라인 폴백 제거.
- `app/(document)/templates/[id]/components/TemplateDetailPageContent.tsx` 의 모든 `t("key","한글")` 폴백 제거 + 키를 ko/en 에 등록(templates.detail.* 7개), "제거하세요" → "삭제하세요".
- `app/(document)/templates/new/components/NewTemplatePageContent.tsx` 동일.
- `app/(billing)/checkout/credit/page.tsx`, `components/bills/*.tsx` 의 인라인 폴백 제거.
- `app/error/page.tsx`: 클라이언트 컴포넌트로 바꾸고 `error.title`("문제가 생겼어요"), `error.description`("요청을 처리하지 못했습니다. 다시 시도하거나 홈으로 돌아가세요."), `error.retryReset`("비밀번호 재설정 다시 요청"), `error.home`("홈으로") 키 사용. `searchParams.type === "auth"` 일 때만 재설정 버튼 표시.

## 수용 기준
- `npx vitest run`, `npx tsc --noEmit` 통과
- `grep -n "오류가 발생" locales/ko.ts` 0건
- `grep -rn 't("[a-zA-Z.]*", *"[가-힣]' app components` 0건
- `grep -rn "크레딧" locales app components --include=*.ts --include=*.tsx | grep -v "app/actions"` 0건
