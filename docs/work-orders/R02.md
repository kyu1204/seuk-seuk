# R02 공통 StatusBadge 와 상태 라벨 표준

## 산출물
- `components/ui/status-badge.tsx` (신규): `export type BadgeStatus = "draft" | "published" | "active" | "completed" | "expired"`; `export function statusBadgeClass(status: BadgeStatus): string` (spec 의 클래스 문자열 반환, published 와 active 는 동일); `export function statusLabelKey(status: BadgeStatus): string` → `status.draft` / `status.published` / `status.published` / `status.completed` / `status.expired`; `export function StatusBadge({ status, className })` 클라이언트 컴포넌트(useLanguage 의 t 사용, completed 일 때 lucide `Check` 12px 아이콘 포함).
- 먼저 `components/ui/status-badge.test.tsx` 작성: 두 순수 함수 검증(컴포넌트 import 금지 → 순수 함수는 `components/ui/status-badge-utils.ts` 로 분리하고 테스트는 그 파일을 import. 컴포넌트 파일은 utils 를 re-export). 즉 파일 2개: `status-badge-utils.ts`(+`status-badge-utils.test.ts`), `status-badge.tsx`(+`status-badge.test.tsx` 는 소스 문자열 검증: `bg-seal-soft` 포함).
