# R01 전역 토큰 교체·클리셰 제거·locale 패리티 테스트

## 목적
docs/design/renewal-spec.md 의 토큰을 적용하고, 홈 이외 화면에 남은 랜딩 템플릿 클리셰 클래스를 제거한다. 이후 모든 태스크가 쓰는 locale 패리티 테스트를 만든다.

## 작업 순서 (TDD 가드 때문에 순서 고정)
1. `locales/ko.test.ts` 생성: ko.ts 와 en.ts 를 import 해 (a) 키 집합이 동일한지, (b) 값이 빈 문자열이 아닌지 검증. `locales/en.test.ts` 생성: en.ts 의 모든 값이 한글([가-힣])을 포함하지 않는지 검증.
2. `app/globals.test.ts` 생성(테스트만; globals.css 는 .ts 가 아니라 가드 대상 아님): `fs.readFileSync("app/globals.css")` 로 `--seal`, `--amber`, `--primary: 213 52% 25%` 존재, `.card-angled`·`.gradient-text`·`.bg-dot-pattern`·`.bg-grid-pattern`·`.notification-banner` 부재를 검증.
3. `app/globals.css` 수정: spec 의 라이트/다크 토큰 값으로 교체, `.bg-dot-pattern` `.bg-grid-pattern` `.gradient-text` `.dark .gradient-text` 블록 삭제. `.home-signature-stroke` 블록과 `.signature-area-label` 블록, body 서체 블록은 유지.
4. `tailwind.config.test.ts` 생성 후 `tailwind.config.ts` 수정: colors 에 `seal: { DEFAULT: "hsl(var(--seal))", soft: "hsl(var(--seal-soft))" }`, `amber: { DEFAULT: "hsl(var(--amber))", soft: "hsl(var(--amber-soft))" }` 추가. 테스트는 config 를 import 해 `theme.extend.colors.seal.soft` 존재 검증.
5. `app/layout.test.tsx` 생성(소스 문자열 검증: `enableSystem` 이 `{false}` 가 아니고 `defaultTheme="system"`) 후 `app/layout.tsx` 수정: `defaultTheme="system"`, `enableSystem` (true).
6. 다음 4개 파일에서 `bg-dot-pattern`·`gradient-text` 클래스 제거(각각 `<basename>.test.tsx` 를 먼저 만들어 소스에 두 문자열이 없음을 검증):
   - `app/(auth)/login/LoginPage.tsx`, `app/(auth)/register/RegisterPage.tsx`, `app/(auth)/register/success/page.tsx`, `app/(sign)/sign/[id]/completed/page.tsx`
   패턴 div(`<div className="absolute inset-0 bg-dot-pattern ...">`)는 요소째 삭제, `gradient-text` 는 클래스만 삭제. 다른 변경 금지(R11 에서 화면을 다시 만든다).

## 금지
- locales 값 변경 금지(이 태스크는 테스트만 추가).
- 홈(`app/(home)/**`) 수정 금지.

## 수용 기준
- `npx vitest run` 통과, `npx tsc --noEmit` 통과
- `grep -rn "gradient-text\|bg-dot-pattern\|bg-grid-pattern\|card-angled" app components` → 0건
- `grep -n "enableSystem={false}" app/layout.tsx` → 0건
