## AuthShell 스펙
`AuthShell({ children, title, description })`: `min-h-screen md:grid md:grid-cols-2`. 좌측 패널 `hidden md:flex flex-col justify-between bg-primary text-primary-foreground p-12`: 상단 로고(FileSignature + app.title), 중앙 `auth.panel.title`("오늘 보낸 계약서,\n오늘 서명받으세요", whitespace-pre-line, `text-4xl font-bold leading-tight`) + `auth.panel.description`("문서를 올리고 서명 칸을 찍은 뒤 링크만 보내면 됩니다. 받는 사람은 가입 없이 휴대폰에서 서명해요.", `opacity-80`) + 미니 카드(`rounded-xl border border-primary-foreground/20 bg-primary-foreground/10 p-5`: 문서명 `auth.panel.sampleDoc`("업무 위탁 계약서") + 오른쪽 `bg-seal text-white` 칩 "완료"는 StatusBadge 대신 정적 span `rounded-full px-2.5 h-6 text-xs bg-seal text-primary-foreground` 로 `status.completed` 텍스트), 하단 `© {year} SeukSeuk`. 우측: `flex items-center justify-center p-6 md:p-12`, 안쪽 `w-full max-w-[380px] flex flex-col gap-6`. 모바일 전용 상단 로고 `md:hidden flex items-center gap-2 mb-6`.

## LoginPage
- AuthShell 로 감싼다. 제목 `login.title`, 부제 `login.noAccount` + 링크 `login.register`("회원가입"). `login.createAccount` 키 사용 중단(값은 두되 미사용).
- 소셜 버튼(카카오, 구글) 44px, 그 아래 구분선 `login.orEmail`("또는 이메일로").
- 비밀번호 필드 라벨 오른쪽에 `login.forgotPassword` 링크(값 "비밀번호 재설정") — `text-sm`, 최소 높이 44px 터치 타깃(`py-2`).
- 비밀번호 보기 토글 버튼(Eye/EyeOff, `aria-label={t("login.togglePassword")}`).
- 폼 레벨 에러 렌더: `state?.error` 가 있으면 필드 아래 `rounded-md bg-destructive/10 text-destructive text-sm px-3 py-2`. 서버 액션이 필드 에러만 주면 그대로 유지.
- 금지 문자열: `bg-dot-pattern`, `gradient-text`, `text-xs text-primary`.

## RegisterPage
- AuthShell. 제목 `register.title`. 약관 문장을 `register.agreePrefix`("") 없이 `register.agreeText`("{{terms}}과 {{privacy}}에 동의합니다") 로 바꾸고 `&` 구분자 제거. 링크 텍스트는 `register.termsOfService`, `register.privacyPolicy`(값 "개인정보처리방침").
- 비밀번호 규칙 힌트 `register.passwordHint`("8자 이상, 영문과 숫자를 포함해 주세요.") 필드 아래 `text-xs text-muted-foreground`. 보기 토글 동일.
- 제출 버튼은 항상 활성. 미동의로 제출 시 체크박스 아래 `register.agreeRequired`("계속하려면 약관에 동의해 주세요.") 표시(클라이언트 상태).

## ForgotPasswordPage
- AuthShell. 제목 `forgotPassword.title`(값 "비밀번호 재설정"). 전송 후 화면의 "다시 보내기"는 실제로 서버 액션을 다시 호출하고, 호출 후 30초 동안 비활성 + `forgotPassword.resendIn`("{{seconds}}초 후 다시 보낼 수 있어요"). `forgotPassword.checkInbox` 값에 "받은함" → "받은편지함".

## register/success
- AuthShell. 제목 `register.success.checkEmail`("이메일을 확인해 주세요"), 설명 `register.success.emailSent`("인증 메일을 보냈어요. 메일의 링크를 누르면 가입이 끝납니다."). 기존 "회원가입이 완료되었습니다!" 키는 미사용.
