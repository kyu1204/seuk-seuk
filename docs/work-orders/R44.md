# R44 서명 패드 품질

## 파일
- 신규 `lib/sign/stroke.ts` (+`stroke.test.ts` 먼저): `midpoint(a, b)`, `scaleForDpr(cssWidth, cssHeight, dpr) → {width, height}` (정수 반올림), `pushStroke(history, stroke)`, `popStroke(history) → {history, removed}` 순수 함수.
- `components/signature-modal.tsx` (+test: `devicePixelRatio` 존재, `quadraticCurveTo` 존재, `signature.undo` 존재, `lastX` 를 `useState` 로 쓰는 코드 부재)

## 스펙
- 캔버스: CSS 크기는 컨테이너 폭 × 높이 220px(모바일 640px 미만에서는 200px). `useLayoutEffect` 로 `scaleForDpr` 결과를 canvas.width/height 에 넣고 `ctx.scale(dpr, dpr)`. 리사이즈 시 기존 스트로크를 재그리기(스트로크 배열 상태 유지).
- 그리기: 포인터 이벤트(`onPointerDown/Move/Up`, `setPointerCapture`)로 통일. 각 스트로크는 점 배열. 렌더는 인접 점 중점을 잇는 `quadraticCurveTo` 스무딩, `lineWidth 2.5`, `lineCap/lineJoin round`, 색 `hsl(var(--foreground))` 값을 getComputedStyle 로 읽어 적용. 마지막 좌표는 `useRef` 로만 관리(리렌더 없음).
- 가이드: 캔버스 하단 24px 위치에 점선 기준선(`ctx.setLineDash([4,4])`, 색 `hsl(var(--border))`), 빈 상태에서 중앙 플레이스홀더 텍스트 `signature.placeholder`("여기에 서명해 주세요", `text-muted-foreground`, canvas 위 절대 배치 div, `pointer-events-none`).
- 버튼: `signature.undo`("되돌리기", Undo2 아이콘, 스트로크 없으면 disabled), `signature.clear`("지우기"), 확정 `signature.sign` 값 "이 서명 사용하기"(스트로크 없으면 disabled).
- 닫기: 스트로크가 있는 상태에서 `onOpenChange(false)` 가 오면 AlertDialog `signature.discardTitle`("그린 서명을 버릴까요?") / `signature.discardConfirm`("버리기") / `common.cancel`.
- 안내 문장 `signature.instruction` 값 "네모 칸 안에 서명해 주세요" 를 캔버스 위쪽으로 이동.
