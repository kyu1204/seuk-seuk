## 레이아웃 스펙
- 상단 sticky(`sticky top-0 z-30 bg-background border-b`): 행 1 `flex items-center justify-between px-4 py-3` — 뒤로가기 ghost(aria-label `common.back`), 중앙 문서명(`font-semibold text-sm truncate`) + `sign.header.meta`("{{page}}/{{pages}}쪽 · 서명 {{completed}}/{{total}}"; 이미지 문서는 쪽 부분 생략 키 `sign.header.metaSingle`), 오른쪽 `sign.batchSign` 값 "한 번에 서명" outline sm 버튼 — 서명 칸이 2개 이상이면 항상 표시, 아직 서명이 없으면 disabled + 툴팁 대신 아래 안내 줄 텍스트. 행 2: 4px 진행 바(`bg-muted` 위 `bg-primary`, width = completed/total).
- 안내 줄(`px-4 py-2 flex justify-between text-sm`): 왼쪽 `sign.clickAreas` 값 "파란 칸을 눌러 서명하세요"(일괄서명 안내가 필요할 때 `sign.batchSignHint`("먼저 한 곳에 서명하면 나머지에 한 번에 적용할 수 있어요")로 교체), 오른쪽 `sign.nextArea`("다음 칸으로") 링크 버튼 → nextUnsignedArea 로 페이지 이동 + `scrollIntoView({block:"center"})`.
- 문서 영역: 기존 렌더 유지. 줌 컨트롤은 문서 아래 중앙 정렬 작은 툴바로 이동(`aria-label` 3개: 축소/확대/원래 크기). 컨테이너 `style={{ touchAction: zoom > 1 ? "none" : "pan-y" }}`.
- 미서명 칸: `animate-pulse` 제거, `border-2 border-dashed border-primary/60 bg-primary/5`; 서명된 칸: `border border-seal bg-seal-soft/60` + 우상단 체크 원(`bg-seal`). 칸 요소는 `role="button" tabIndex={0} aria-label={t("sign.area.label", {index})}`("서명 칸 {{index}}") + Enter/Space 처리. 텍스트 칸은 `sign.clickToType` 값 "여기에 입력", 서명 칸 라벨 `sign.clickToSign` 값 "여기에 서명".
- PDF 페이지 칩 줄(문서 아래, `flex gap-2 justify-center flex-wrap`): 각 페이지 `sign.pageChip`("{{page}}쪽") + 잔여가 있으면 " · {{count}} 남음" (remainingByPage), 현재 페이지 `bg-primary/10 text-primary`.
- 하단 sticky(`sticky bottom-0 bg-background border-t px-4 pt-3 pb-5 flex flex-col gap-2`): 제출 버튼 48px. 남은 칸이 있으면 disabled 라벨 `sign.submit.remaining`("서명 {{count}}곳을 더 채우면 제출할 수 있어요"), 없으면 `sign.saveDocument` 값 "문서 제출하기". 아래 `sign.completed.noEdit` 값 "제출하면 서명을 수정할 수 없습니다." `text-xs text-muted-foreground text-center`.
- 제출 클릭 시 AlertDialog: 제목 `sign.submit.confirmTitle`("문서를 제출할까요?"), 설명 `sign.submit.confirmDescription`("제출한 뒤에는 서명을 바꿀 수 없습니다."), 확인 `sign.submit.confirm`("제출하기"), 취소 `common.cancel`.
- 처리 모달 문구: `sign.progress.title` 값 "서명한 문서를 만드는 중이에요", 단계 문구 3개로 축약: `sign.progress.compositing`("서명을 문서에 넣는 중…"), `sign.progress.uploading`("문서를 만드는 중…"), `sign.progress.finalizing`("거의 다 됐어요…"). `sign.progress.description` 값 "창을 닫지 마세요. 보통 10초 안에 끝나요." 처리 중 `beforeunload` 핸들러 등록(완료 후 해제).
- 에러 배너를 문서 위(안내 줄 아래)로 이동, `rounded-md bg-destructive/10 text-destructive px-3 py-2 text-sm` + `common.retry` 버튼(마지막 실패 동작 재시도). 영어 문구 → 키: `sign.error.saveSignature`("서명을 저장하지 못했습니다. 다시 시도해 주세요."), `sign.error.upload`("서명한 문서를 만들지 못했습니다. 다시 시도해 주세요."), `sign.error.loadDocument`("문서를 불러오지 못했습니다. 새로고침해 주세요."). 이미지 alt: 문서 `alt={documentName}`, 서명 `alt={t("sign.area.signedAlt")}`("서명됨").
- 일괄서명 확인 문구 `sign.batchSignConfirm` 값 "남은 {{count}}곳에 같은 서명을 넣습니다. 계속할까요?" (PDF 이면 `sign.batchSignConfirmPage` "이 쪽의 남은 {{count}}곳에…"). 부분 실패 시 토스트 `sign.batchSign.partial`("{{done}}곳은 적용했고 {{failed}}곳은 실패했어요. 실패한 칸을 다시 눌러 주세요.").
- 다크 하드코딩(`bg-white`, `text-gray-*`) 전부 토큰으로. `aria-live="polite"` 영역에 진행 텍스트를 렌더.
