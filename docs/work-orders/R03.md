## 파일
`components/site-header.tsx` (먼저 `components/site-header.test.tsx`: 소스 문자열 검증 — `aria-label` 2회 이상, `bg-transparent` 부재, `href="/dashboard"` 존재), `components/theme-toggle.tsx`(+test: `aria-label` 존재), `components/language-selector.tsx`(+test: `aria-label` 존재).

## 스펙
- 헤더: `sticky top-0 z-50 h-16 border-b bg-background/95 backdrop-blur`. 스크롤 효과·`bg-transparent` 분기 삭제(`showScrollEffect` prop 은 호환을 위해 받되 무시).
- 왼쪽: 로고(FileSignature 22px + `app.title` `font-bold text-lg`). 로그인 상태면 로고 오른쪽 `hidden md:flex gap-6 text-sm` 내비: `header.nav.documents`("내 문서") → /dashboard, `header.nav.pricing`("요금제") → /pricing, `header.nav.bills`("결제") → /bills. 현재 경로(`usePathname`)와 prefix 일치하면 `text-foreground font-semibold`, 아니면 `text-muted-foreground`.
- 오른쪽: ThemeToggle, LanguageSelector, 로그인 시 UserAvatar, 아니면 `login.logIn` 버튼(`variant="default"`, size sm).
- ThemeToggle 트리거 버튼에 `aria-label={t("header.themeToggle")}`("테마 변경"), 마운트 전 플레이스홀더 폭을 `w-9`로 고정하고 라벨 텍스트 제거(아이콘 전용, 36px). LanguageSelector 트리거 `aria-label={t("header.languageSelect")}`("언어 선택").
- locale 추가(ko/en): header.nav.documents(내 문서/Documents), header.nav.pricing(요금제/Pricing), header.nav.bills(결제/Billing), header.themeToggle(테마 변경/Change theme), header.languageSelect(언어 선택/Select language).
