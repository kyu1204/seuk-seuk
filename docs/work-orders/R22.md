# R22 카드 통일(DocumentTile)·체크박스·접근성·상태 필터

## 신규
- `components/dashboard/document-tile.tsx` (+ `document-tile.test.tsx`: 소스에 `role="button"`, `aria-pressed`, `Checkbox`, `h-36`, `hover:border-primary/30` 존재, `scale-` 부재)
  props: `{ href?: string; onClick?: () => void; status: BadgeStatus; title: string; metaLeft: string; metaRight?: string; selectable?: boolean; selected?: boolean; onSelectToggle?: () => void; disabledReason?: string; thumbnail?: ReactNode; actions?: ReactNode }`
  spec 의 카드 규격. selectable 이면 썸네일 좌상단에 `components/ui/checkbox` (`aria-label={title}`), 카드 루트는 `role="button" tabIndex={0} aria-pressed={selected}` + Enter/Space 로 onSelectToggle. selectable 이 아니면 루트는 `Link href`. `disabledReason` 이 있으면 카드 `opacity-60` + 썸네일 하단에 `text-xs text-muted-foreground` 로 이유 텍스트(title 속성 금지). `actions` 는 본문 오른쪽 하단에 렌더(아이콘 버튼은 호출측이 aria-label 부여).

## 교체 (각 `.test.tsx` 먼저: `DocumentTile` import 존재, `<svg` 직접 작성 체크박스 부재, `border-gray-300` 부재)
- `components/dashboard/document-card.tsx` → DocumentTile 사용. metaLeft = 생성일(기존 포맷 함수 유지), metaRight = `dashboard.card.signatures`("서명 {{completed}}/{{total}}") 또는 초안이면 `dashboard.card.areas`("칸 {{count}}개"). 선택 불가 사유는 `dashboard.bulkDelete.cannotDelete`(값 "발행 중인 문서예요. 먼저 발행을 삭제해 주세요.").
- `components/dashboard/publication-card.tsx` → DocumentTile. metaRight = `dashboard.publications.card.documentCount`(값 "문서 {{count}}개"로 변경, 조립 방식 제거). actions: 링크 복사 버튼(`aria-label={t("dashboard.publications.card.copyLink")}` 값 "링크 복사"; 복사 후 토스트 `dashboard.publications.card.copied`("링크를 복사했어요")), 외부 열기 버튼(aria-label `dashboard.publications.card.open`("서명 페이지 열기")), 삭제 버튼(aria-label `dashboard.publications.delete.title`).
- `components/dashboard/templates-list.tsx` 의 카드 → DocumentTile (`role="link"` 제거). metaRight = `templates.card.areas`("칸 {{count}}개").
- `components/dashboard/status-filter.tsx` — 칩 스타일: 선택 `bg-primary/10 text-primary border-primary/30`, 비선택 `border text-muted-foreground bg-transparent`, 높이 30px, 개수는 라벨 뒤 공백+숫자. 자체 `mb-6` 제거(부모가 간격 담당). 필터 라벨은 status 키 재사용.
- `components/dashboard/bulk-delete-header.tsx` — X 버튼 `aria-label={t("dashboard.selectionMode.exit")}`, `sticky top-16`. `dashboard.selectionMode.enter` 값 "여러 개 선택", exit 값 "선택 취소".
- `components/dashboard/dashboard-skeleton.tsx` — 본문을 `DocumentCardsSkeletonGrid` 재사용으로 교체, gap 은 그리드와 동일 `gap-5`.
- 그리드: `grid gap-5 sm:grid-cols-2 lg:grid-cols-4` 로 3곳(document/publication/template 목록) 통일.
