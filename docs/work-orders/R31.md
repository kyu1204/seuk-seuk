# R31 업로드/서명 칸 지정 화면 리뉴얼과 발행 연결

## 파일 (각 `.test.tsx` 먼저)
- `app/(document)/upload/components/UploadPage.tsx` — 테스트: `upload.page.title` 존재, `text-3xl` 부재.
- `components/document-upload.tsx` — 테스트: `upload.saveAndPublish` 존재, `=== "지우기"` 부재, `bg-white/90`·`bg-red-50`·`bg-gray-100` 부재, `aria-label` 3회 이상.
- `components/area-selector.tsx` — 테스트: `max-h-[50vh]` 부재.

## 스펙
- 페이지 헤더(spec 패턴): h1 `upload.page.title`("문서 올리기"), 설명 `upload.page.description`("PDF나 사진을 올리고 서명받을 칸을 지정하세요."). 드롭존 제목은 `upload.dropzone.title`("여기에 문서를 놓으세요"), 부제 `upload.dragDrop`(값 "클릭해서 파일을 고르거나 끌어다 놓으세요 · PDF, JPG, PNG · 최대 10MB"). `upload.title`("문서 관리") 사용 중단.
- 파일이 올라간 뒤(편집 단계) 레이아웃: 상단 바 `flex items-center justify-between gap-4 mb-5` — 왼쪽 뒤로가기 ghost 버튼(`aria-label={t("common.back")}`) + 파일명 `text-xl font-bold` + 메타 `text-xs text-muted-foreground`(`upload.meta`: "{{pages}}쪽 · 서명 칸 {{signatures}}개, 텍스트 칸 {{texts}}개"), 오른쪽 `[저장하기 outline][저장하고 발행하기 default]`.
  본문 `grid lg:grid-cols-[260px_minmax(0,1fr)] gap-5`: 좌측 패널 카드 2개(칸 추가: `upload.signature` 버튼 default/ `upload.textArea` 버튼 outline + 힌트 `upload.areaHint`("칸을 고른 뒤 문서 위에서 끌어서 놓으세요."); 지정한 칸 목록 `upload.areaList`("지정한 칸 {{count}}") 각 행 "서명 · {{page}}쪽" / "텍스트 · {{page}}쪽" + 삭제 아이콘 버튼 aria-label `common.delete`). 우측 캔버스 카드: 상단 툴바(페이지 이전/다음 `aria-label`, "n / m쪽", 줌 %) + 회색(`bg-muted`) 영역에 문서. 기존 플로팅 툴바(`absolute top-4 right-4 bg-white/90`)는 이 툴바로 대체.
- 모바일: 좌측 패널이 캔버스 아래로 내려가고(`order-2`), 캔버스 높이 제한(`max-h-[50vh]`) 제거 후 `overflow-auto` 로 자연 높이. 드래그 중에는 컨테이너에 `touch-action: none`, 아니면 `pan-y`.
- "저장하고 발행하기": 기존 저장 로직을 호출한 뒤 성공하면 `router.push(\`/publish?doc=\${documentId}\`)`. "저장하기"는 기존처럼 /dashboard 이동 + 토스트 `upload.saved`("저장했어요").
- 서명 칸 0개로 저장 시 다이얼로그: 제목 `upload.noAreas.title`("서명 칸이 없어요"), 설명 `upload.noAreas.description`("칸 없이 저장하면 받는 사람이 서명할 곳이 없습니다. 그래도 저장할까요?"), 버튼 `upload.noAreas.addAreas`("칸 지정하기", 닫기) / `upload.noAreas.saveAnyway`("그대로 저장"). 언어 판별용 문자열 비교 코드 삭제.
- 하드코딩 색 → 토큰: 에러 박스 `bg-destructive/10 text-destructive`, 회색 배경 `bg-muted`.
- 한글 하드코딩("PDF 페이지를 캡처할 수 없습니다.") → `upload.error.capture`("PDF 페이지를 읽지 못했습니다. 다른 파일로 다시 시도해 주세요.").
