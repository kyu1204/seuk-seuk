# R21 대시보드 헤더·사용량 요약·탭 URL 동기화

## 파일 (각 `.test.tsx` 먼저)
- `components/dashboard/dashboard-header.tsx` — 테스트: 소스에 `dashboard.header.description`, `dashboard.upload.document`, `dashboard.publish` 존재, `text-2xl sm:text-3xl` 부재.
- `components/dashboard/usage-widget.tsx` — 테스트: 소스에 `usage.summary.sent`, `usage.summary.active`, `usage.managePlan` 존재, `useState(false)` 부재.
- `components/dashboard/dashboard-content.tsx` — 테스트: 소스에 `useSearchParams` 와 `router.replace` 존재. 추가로 순수 함수 `resolveTab(value: string | null): TabType` 를 `components/dashboard/dashboard-tabs.ts` 로 분리(+`dashboard-tabs.test.ts`): "documents"|"publications"|"templates" 외에는 "documents".
- `components/dashboard/templates-list.tsx` — 테스트: `router.push("/dashboard?tab=publications")` 문자열 존재.

## 스펙
- 헤더: spec 의 페이지 헤더 패턴. h1 `dashboard.header.title`("내 문서"), 설명 `dashboard.header.description`(값을 "문서를 올리고 서명을 받아보세요."로 변경). 오른쪽 버튼: `variant="outline"` Link2 아이콘 + `dashboard.publish`(값 "발행하기") → /publish, `default` Upload 아이콘 + `dashboard.upload.document`(값 "문서 올리기") → /upload. 기존 드롭다운(문서 업로드/템플릿 만들기)은 "문서 올리기" 버튼 옆 `DropdownMenu` 대신 템플릿 만들기를 템플릿 탭 안 빈 상태/헤더 버튼으로 옮긴다(templates-list 헤더에 `templates.create`("템플릿 만들기") 버튼이 이미 있으면 유지).
- 사용량 요약: usage-widget 을 항상 펼친 1줄 바(`rounded-xl border bg-card px-5 py-3.5 flex flex-col md:flex-row gap-5 md:items-center`)로 재구성: 항목 2개(각 `flex-1`: 라벨 + `n/m건` + 6px 진행 바 `bg-muted`/`bg-primary`), 오른쪽 `usage.managePlan`("플랜 관리") 링크 → /pricing. 라벨: `usage.summary.sent`("이번 달 보낸 문서"), `usage.summary.active`("진행 중인 문서"). 무제한이면 `usage.monthly.unlimited`. 80% 이상이면 진행 바 `bg-amber`, 100% 이면 `bg-seal` 와 `usage.limit.reachedHint`("한도에 도달했어요. 플랜을 바꾸거나 추가문서를 구매하세요.") 표시. 접기 상태·기존 카드 UI 삭제. 기존 데이터 fetch 로직은 유지.
- 탭: `activeTab` 을 `useSearchParams().get("tab")` 로 초기화(resolveTab)하고, 탭 변경 시 `router.replace(\`/dashboard?tab=\${tab}\`, { scroll: false })`. `useEffect` 로 searchParams 변경을 state 에 반영(뒤로가기 대응). 탭 라벨 옆 개수 표시(`text-muted-foreground ml-1`), 기존 카운트 데이터가 없으면 문서 탭만 표시.
- templates-list 의 발행 성공 후 이동을 `/dashboard?tab=publications` 로.
