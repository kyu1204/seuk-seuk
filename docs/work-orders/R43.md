## 파일 (각 `.test.tsx` 먼저)
- 신규 `app/(sign)/sign/[id]/components/SignComplete.tsx` (+test: `sign.complete.remaining` 존재, `bg-seal` 존재, `text-gray-` 부재)
  props: `{ documentName: string; signedCount: number; downloadButton: ReactNode; remainingDocuments: { id: string; name: string; completed: number; total: number }[]; onContinue: (id: string) => void; onBackToList: () => void; ownerNotified: boolean }`
  레이아웃 `max-w-md mx-auto px-5 py-10 flex flex-col items-center gap-6 text-center`: 64px 원(`bg-seal text-primary-foreground`) + Check 30px → h1 `sign.complete.title` 값 "서명이 끝났습니다" → `sign.complete.description` 값 "{{name}}에 서명 {{count}}곳을 제출했어요. 서명한 문서를 내려받아 보관하세요." → 다운로드 카드(`w-full rounded-xl border bg-card p-4 flex items-center gap-3 text-left`: FileText 아이콘, 파일명, `sign.complete.signedAt`("서명 포함 · {{date}}"), 오른쪽 downloadButton) → remainingDocuments 가 있으면 카드: `sign.complete.remaining`("아직 서명할 문서가 {{count}}개 남았어요") + 첫 문서 행(이름, 서명 n/m, 버튼 `sign.complete.continue`("이어서 서명")) → ownerNotified 이면 `sign.complete.ownerNotified`("보낸 사람에게도 완료 알림이 갔습니다.") `text-xs text-muted-foreground`. 남은 문서가 없고 publication 이 완료되지 않았으면 `sign.documentList.backToList` outline 버튼.

- `SignedDocumentDownloadButton.tsx` — 다운로드 실패 시 토스트 `sign.completed.downloadError` 값 "파일을 내려받지 못했습니다. 다시 시도해 주세요." 성공 처리 조건을 실제 응답 성공으로. `SignedDocumentBundleButton.tsx` 의 파일명 "서명문서.zip" → `sign.download.bundleName`("서명문서") 키 + ".zip".
