## 게이트 화면 스펙
`max-w-md mx-auto px-5 py-8 flex flex-col gap-6`:
1. `sign.gate.sentBy`("{{sender}}님이 보낸 서명 요청", sender 비어 있으면 `sign.gate.sentByUnknown`("서명 요청")) `text-xs text-muted-foreground`
2. h1 발행 이름 `text-2xl font-bold`
3. `sign.gate.summary`("문서 {{docs}}개 · 서명 칸 {{areas}}곳 · {{date}}까지", date 는 `M월 D일` / en `MMM D`, expiresAt 없으면 날짜 부분 생략 키 `sign.gate.summaryNoExpiry`)
4. 카드: Lock 아이콘 + `sign.password.title` 값 "비밀번호를 입력해 주세요"; 설명 `sign.password.description` 값 "보낸 사람에게 받은 비밀번호를 입력하면 문서를 볼 수 있어요."(`sign.password.instruction` 미사용); 입력 48px `autoComplete="current-password"` + 보기 토글(aria-label `login.togglePassword`); 버튼 `sign.password.verify` 값 "문서 열기" 48px; 아래 `sign.password.help`("비밀번호를 모르시나요? 보낸 사람에게 문의하세요.").
   에러: `sign.password.incorrect` 값 "비밀번호가 맞지 않습니다. 다시 확인해 주세요.", `sign.password.error` 값 "비밀번호를 확인하지 못했어요. 잠시 후 다시 시도해 주세요." 입력 아래 `text-destructive text-sm`.
5. 푸터 `sign.password.trustNote` 값 "이 링크는 슥슥을 통해 전송되었습니다" + 약관·개인정보처리방침 링크.
